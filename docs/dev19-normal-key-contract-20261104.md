# dev19 普通 Key 与 Harness 管理项的识别

2026-11-04，Windows 本地候选 `0.1.0rc6.dev19`。本轮依据账号持有人提供的两份控制台只读列表响应和对应页面截图修复删除准备。公开资料与测试只使用字段形态、类别和虚构身份。

## 实际改动

- 删除准备接受精确的 `NORMAL` 类型。程序先按完整 Tracking ID 对应 HTTP 与网页的全部条目，再核对绑定的名称，只从选中目标读取掩码标识和整数秒创建时间。`DSH` 作为 Harness 管理的身份项参加全表核验。选中它做只读预检、强制删除或达额处理时，普通撤销流程在发出提交许可前返回 `KEY_TARGET_NOT_DELETABLE`。
- 旧夹具中的 `USER` 归入未分类类型。身份可独立核对的未分类旁观项仍参加完整列表检查，选为目标则返回 `KEY_TARGET_KIND_UNSUPPORTED`。诊断查看器兼容旧记录中的 `USER` 标签。
- 网页行定位也允许列表重新排序。程序比较完整身份集合，再从当前快照定位行，并重新读出该行的名称与完整 ID。身份发生变化时停止定位。

## 改动理由

两份 `GET /api/v0/users/get_api_keys` 响应均为 HTTP 200，顶层 `code` 和 `data.biz_code` 均为 0。四项数据给出了本次适配依据。

| 当前样本中的条目 | HTTP 字段 | 网页观察 |
| --- | --- | --- |
| 三项普通 Key，含所选目标 | `key_type = NORMAL`，各有带星号的 `sensitive_id` 和整数 `created_at` | 普通项显示编辑和删除控件 |
| 一项 Harness 管理的 Key | `key_type = DSH`，`sensitive_id` 为空字符串，`created_at` 为整数 | 显示 `App-managed` 和由 Harness 管理，普通编辑与删除控件置灰 |

在这次 HTTP 响应里，Harness 排第一，目标排第四。网页上目标排第一，Harness 排第二。HTTP 中第二项和第四项同为 `NORMAL`，只有完整 ID 能区分它们。账户配额摘要的已用数为 3，身份核验实际比较全部 4 项。

用相同结构、虚构数据离线重放，dev17 的全表类型检查返回 `KEY_KIND_INVALID`，dev18 对所选普通目标返回 `KEY_TARGET_KIND_UNSUPPORTED`，dev19 对普通目标准备成功并拒绝 Harness 项。这解释了旧版在这类列表上的失败路径。11 月 3 日故障时的原始 HTTP 正文仍然缺失。

## 已经运行的验证

- 定向离线回归 120 项通过，11.367 秒。将四项 HTTP 列表和网页列表独立排列，覆盖 576 种组合。模拟数据含两个同名普通项，每次仅向模拟传输提交一次绑定目标的 ID、掩码和创建时间。
- 将真实解析器接入模拟撤销流程，在准备复核及提交后再次改变排列，核实目标缺席并保留全部对照身份。给 Harness 项填上完整的模拟删除参数，预检和撤销仍在许可前拒绝，模拟 POST 次数为 0。
- 本地 Chromium 页面把两个同名行重新排序后，定位命中原 Tracking ID。改变其中一项的身份后，定位停止。
- 完整离线回归 **948 项通过，0 失败、0 跳过，用时 279.312 秒**。定向用例已包含在全量中。
- Windows x64 构建通过。成品 GUI 启退 1.890 秒，内置 Chromium 空白页检查 1.469 秒，退出码均为 0。
- 候选来源检查覆盖 135 个源码和资料文件。指定凭据及会话标记扫描零命中，81 个本地文档链接有效。校验了上一候选的 134 个源码文件和原桌面源码的 117 个文件。
- build_id 为 `code-sha256-bf2223031e3b636a196fd10ee07ea4b964fe205c60c79dc00535f7972e7b023f`。EXE 的 SHA-256 为 `847b4bd0405b5c82f2a144441e9e74ff5129cd604a508a18f79df4340dcb82a7`。

## 仍未解决或未验证的事项

- 已观察到真实只读列表的类别和字段形态。dev19 在用户登录会话内的完整只读预检、真实单次撤销、独立核实目标缺席以及旧凭据失效，仍待专用目标验收。正额度真实消费跨线的周期自动撤销也待验收。
- 本版完整网页列表沿用最多 200 行的现有读取保护。此次平台画面显示普通 Key 容量为 300，超过当前读取保护范围的真实账号尚未适配。程序会停止，不采用截断的身份集合。
- Excel/WPS 真实导入、长期运行与同机干扰仍待专项验证。

现场下一步是在全自动管理停止时，登录并进入 API keys 列表，回到软件读取费用，选中普通专用目标，点击“检查删除准备（只读）”。本步的验收结果是界面显示“准备通过”，并且平台没有发生删除。
