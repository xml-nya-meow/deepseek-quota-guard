# dev6：斩杀线预填与深浅色界面

日期：2026-11-01（UTC+8）；版本：`0.1.0rc6.dev6`，候选预发布。

## 一、实际改动

- 主界面与首次设置增加斩杀线和新表填充值选择。斩杀线最小 0，最多 18 位小数；默认生成模式仍为 `-1`。保存默认值不改已有人员额度，也不启动管理。
- 首次填写窗口按选择预填草稿；确认保存时明确将未填姓名行设为 `-1`，已命名行保留金额。普通打开已有表格不重新预填；导出的 Excel 模板按人数与默认金额生成，正式导入校验保持严格。
- 偏好兼容旧轮询间隔格式，保存间隔与保存新表默认相互保留；损坏时保留原文件，默认生成 `-1`，不静默覆盖。
- 外观提供跟随系统、浅色、深色三种模式，默认跟随 Windows 应用主题，每 5 秒检查变化。覆盖表格、输入框、状态、处理汇报和本软件填写窗口；外观偏好独立保存，系统设置只读。
- 更新 README、使用说明、验证计划和构建排除项；版本递增为 dev6，旧包继续保留。
- 构建组件路径核对改为调用随包 Playwright 的公开 JavaScript 入口，并设 20 秒超时；继续检查锁定版本、路径归属与文件存在，应用运行时浏览器代码没有改变。

## 二、改动理由

用户明确斩杀线是未来新表的默认个人额度，而非额外的全局删除条件。现有 `-1` 跳过、`0` 零额度触发、正额度与公共额度比较以及身份/目标核验均保持原样；已有人员金额不会因默认值改变。

空姓名加非负金额不能直接进入正式管理。首次设置先创建可恢复的 `-1` 正式表，再打开预填草稿；取消不写入草稿，保存时明确处理未命名行。导出模板仍须填写后才能通过导入，避免新表被误识别为损坏或把空白人员纳入管理。

深浅色使用支持自定义配色的 ttk 主题，切换只影响显示。Windows 原生消息框和文件选择框仍由系统绘制，不修改操作系统外观。
